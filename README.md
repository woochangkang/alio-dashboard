# 공공기관 공시 대장 — ALIO 데이터셋 안내서

[**→ 사이트 보기**](https://woochangkang.github.io/alio-dashboard/)

한국 공공기관 경영정보 공개시스템([ALIO](https://www.alio.go.kr))에서 수집한 355개 공시기관 데이터셋의 구조·변수·분포를 정리한 단일 페이지 안내서. 자료가 **어떻게 생산되었는지**, **어떤 변수가 추출되었는지**, **각 변수가 어떤 값을 갖는지**를 보여주고, 모든 그림에 읽는 법을 붙였다.

## 무엇이 들어 있나

| 절 | 내용 |
|---|---|
| 1 · 자료의 생산 | 원자료 4계층(기관 마스터 355 · 통계항목 559 · 보고서 62,141 · 게시판 81,474), 항목 트리, 연도 창의 한계 |
| 2 · 추출 변수 | 원자료 → 파싱 → 분석 단위 계보, 주요 산출물 10종, **핵심 20개 변수의 기술통계** |
| 3 · 변수 탐색기 | **321개 통계 변수의 기술통계**를 검색·정렬 (n · 기관 수 · 0값 · 평균 · 표준편차 · 사분위 · 최대) |
| 4 · 기관 분포 | 유형 · 주무부처 · 17개 시·도 · 설립연도 · 정부지원 의존도 · 규모 시계열 |
| 5 · 임원 분포 | 임명 spell 11,821건의 6범주 정치성 구성 — 직위별 · 기관유형별 · 임명연도별, 임기 구조, 중도이탈 |
| 6 · 계약·감독 | 수의계약 644,239건, 국회·감사원 지적 13,948 레코드 |
| 7 · 회전문·징계 | 퇴직 임·직원 재취업 808건(날짜 유효 799건의 37.4%가 퇴직 익일 내), 징계처분 10,154건 |
| 8 · 생산 과정 | 수집·파싱·분류의 각 단계에서 내린 판단과 알려진 문제 |

## 데이터

| 파일 | 내용 |
|---|---|
| [`data/item_descriptives.csv`](data/item_descriptives.csv) | 321개 통계 변수의 기술통계 (기관×연도 셀 기준) |
| [`data/site_data.json`](data/site_data.json) | 이 페이지가 그리는 모든 집계값 |

**공개 범위**: 집계값만 싣는다. 임원·재취업자 성명, 개별 정치성 분류 라벨 등 개인 식별 정보는 포함하지 않는다. 원자료(38.8 GB)는 ALIO의 공개 공시자료이며 이 저장소에서 재배포하지 않는다.

## 수치의 출처

모든 수치는 2026-09-01에 프로젝트의 `data/processed/`·`data/raw/`를 직접 집계해 산출했다. **회귀 추정 결과는 포함하지 않는다** — 이 페이지의 목적은 자료 구조의 소개이지 분석 결과의 발표가 아니다.

**정정 (2026-10-23)**: ① 2025년 정권교체일 `2025-06-04`를 추정에서 확정으로 고침(궐위선거로 선관위 당선인 결정과 동시에 임기 개시, 코딩값은 원래 맞았으므로 수치 변동 없음). ② 재취업 37.4%·간격 중앙값의 분모를 날짜 유효 799건으로 명시하고 중앙값을 16일로 정정(기존 15.5일은 날짜 역전 3건 포함). ③ 연도별 임명·지적·재취업 그림에 창 밖 생략 건수 각주 추가. ④ 수의계약 총액 증가율의 기간을 2021→2024로 명시.

주요 대조값: 기관 355 · 임명 spell 11,821 · 분류 대상 임원 11,124 · 수의계약 644,239 · 지적 레코드 13,948 · 재취업 808 · 징계처분 10,154 · 통계패널 459,417행.

## 알려진 한계

- **연도 창** — ALIO는 최근 5년만 공개한다. 2021년 이전은 도달 불가이며 재수집으로도 해결되지 않는다.
- **임원 분류 미검증** — 6범주 라벨은 LLM 배치 분류 결과이고 골드샘플 150건의 사람 코딩이 대기 중이다. 라벨 기반 수치는 모두 잠정값이다.
- **좌측절단** — 2021년 이전에 임명되어 종료된 spell은 관측되지 않는다. 임명연도가 이를수록 장기 재직자로 편향된다.
- **2026년은 부분 연도** — 임원 공시 6월 13일까지, 수의계약은 직전 해의 23%.
- **설립일은 정수 YYYYMMDD** — `fdate`(예: `19870730`)를 날짜 파서에 그대로 넣으면 epoch 나노초로 해석되어 전부 1970년이 된다. `df.fdate.astype(str)`로 변환 후 파싱할 것.
- **재취업 공시는 자회사 한정** — 3192의 공시 기준은 "최근 5년 퇴직한 임·직원이 자회사(출자회사) 등으로 재취업한 경우"다. 민간기업·협회행은 포착되지 않으므로 '관피아 전반'의 측정치가 아니다.

## 기술

의존성 없는 단일 HTML 파일. 차트는 인라인 SVG로 직접 그렸고 데이터는 파일에 포함되어 있다. 범주형 색상은 [OKLab 기준 색각 이상 분리도 검증](https://en.wikipedia.org/wiki/Color_blindness)을 통과한 배열을 사용한다(최악 인접쌍 ΔE 16.2, 라이트 모드 기준).
